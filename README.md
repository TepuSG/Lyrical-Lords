Welcome to Lyrical Lords! A web based party game about writing songs with friends!
Below is some basic instructions on starting a game, and direcctions for gameplay.

How to Start a Game:
1. To start, players will enter a lobby based on their entered lobby code. 
2. If at least three players have joined, the game can start!

How to Play:
1. In the first round, each player will write the title of their song.
2. Once each player has submitted their song title, they are given someone elses song title and asked to provide its first lyric.
3. In all future rounds, players are given the previously written lyric with no other context about the song. They are then asked to provide the nexy lyric.
4. New Rounds continue to start until each plalyer has written a lyric for each song.
5. At the end, the lyrics and song title are laid out for players to read and enjoy.
6. Sing your newly written songs!
